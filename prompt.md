Bonsoir,

Voici une description de notre projet 

Nom du projet : LearnCraft

Objectif : Développer une application web d'apprentissage interactif dédiée à la programmation et aux nouvelles technologies. L'objectif est de guider l'utilisateur à travers des "roadmaps" structurées, combinant des micro-leçons théoriques et une mise en pratique immédiate via des projets concrets adaptés à son niveau.

Fonctionnement : L'utilisateur choisit un parcours d'apprentissage (ex: Développement Web, Python). Le contenu est divisé en chapitres courts suivis de quiz pour consolider les acquis. L'application intègre un mentor IA capable d'expliquer les concepts complexes, de traduire le contenu (notamment en français, pour pallier un manque sur le marché actuel), et d'assister au débogage du code.

Technologies envisagées :

Front-end : NextJS

Back-end : firebase

Intelligence Artificielle : Intégration d'un LLM (ex: API Gemini) pour le mentorat interactif et la génération de contenu.

Le dépôt GitHub est actuellement en cours d'initialisation et nous vous le transmettrons dès que l'architecture de base sera en place.
